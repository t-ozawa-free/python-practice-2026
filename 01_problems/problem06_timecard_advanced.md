# 問題6: 深夜勤務を含む給与計算

## 難易度
★★★☆☆ (実務レベル)

## 課題
深夜勤務や日付をまたぐ勤務を含む「input/timecard_advanced.csv」から給与を計算し、「output/salary_advanced.txt」に出力してください。

## 条件
* 基本時給: 1200円
* 22:00～翌5:00は深夜割増（時給1.25倍 = 1500円）
* 日付をまたぐ勤務も正しく計算します（例: 23:00～翌2:00 = 3時間）
* 深夜時間帯を含む場合、通常時間と深夜時間を分けて計算します
* 終了時刻が開始時刻より前の場合の判定:
  - 開始時刻が20:00以降 OR 終了時刻が08:00以前 → 日跨ぎと判断
  - それ以外 → エラーとして「データエラー」と表示
* 支給金額は小数点以下切り捨て、3桁区切りで表示します

## 入力ファイル
`input/timecard_advanced.csv`

## 出力ファイル
`output/salary_advanced.txt`

## 出力形式例
```
給与明細（深夜勤務含む）
==================
01-05, 20:00, 01:00(+1), 通常3.0h, 深夜2.0h, 6,600円
01-08, 10:00, 15:00, 通常5.0h, 深夜0.0h, 6,000円
01-10, 15:00, 10:00, データエラー
...
==================
総勤務時間: 98.0時間（通常78.0h + 深夜20.0h）
支給金額: 123,600円
```

## ヒント
* `datetime` モジュールを使って時刻計算を行います
* 日付をまたぐ場合は `timedelta(days=1)` を追加します
* 深夜時間帯（22:00～5:00）との重複部分を計算します
* 終了 < 開始の場合は異常データとして処理します
