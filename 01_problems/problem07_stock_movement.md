# 問題7: 在庫の入出庫管理

## 難易度
★★★☆☆ (実務レベル)

## 課題
商品の入出庫履歴が記録された「input/stock_movement.csv」から、商品ごとの現在庫数を計算し、在庫状況レポートを出力してください。

## 条件
* 「入庫」は在庫を増やし、「出庫」は在庫を減らします
* 商品ごとに現在庫数を計算します
* 在庫がマイナスになった商品は「在庫不足エラー」として記録します
* 在庫数が安全在庫（20個）を下回った商品は警告を表示します
* 商品コード順に並べて出力します

## 入力ファイル
`input/stock_movement.csv`

## 出力形式例
```
在庫状況レポート
==================
商品: P001 ボールペン（黒）
現在庫数: 45個
状態: 正常
------------------
商品: P002 ボールペン（赤）
現在庫数: 15個
状態: ⚠️ 安全在庫を下回っています
------------------
商品: P003 ノート
現在庫数: -5個
状態: ❌ 在庫不足エラー
------------------
...
==================
正常: 8商品
警告: 3商品
エラー: 2商品
```

## ヒント
* 辞書を使って商品ごとに在庫を管理します
* 各行の「入庫」「出庫」に応じて在庫数を増減します
* 最終的な在庫数をチェックして状態を判定します
