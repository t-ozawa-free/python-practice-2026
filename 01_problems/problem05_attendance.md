# 問題5: 社員の出勤簿管理

## 難易度
★★☆☆☆ (基本)

## 課題
社員の出勤記録が記録された「input/attendance.csv」から、各社員の出勤日数と欠勤日数を集計し、レポートを出力してください。

## 条件
* 社員ごとに出勤日数、欠勤日数、出勤率を計算します
* 出勤率は `(出勤日数 / (出勤日数 + 欠勤日数)) * 100` で計算します
* 出勤率は小数点第1位まで表示します
* 社員IDの昇順で並べて出力します
* 出勤率が90%未満の社員には「※要確認」と表示します

## 入力ファイル
`input/attendance.csv`

## 出力形式例
```
出勤状況レポート
==================
社員ID: E001
社員名: 山田太郎
出勤日数: 20日
欠勤日数: 2日
出勤率: 90.9%
------------------
社員ID: E002
社員名: 佐藤花子
出勤日数: 18日
欠勤日数: 4日
出勤率: 81.8% ※要確認
------------------
...
```

## ヒント
* 辞書を使って社員ごとにデータを集計します
* ステータスが「出勤」「欠勤」のものをカウントします
