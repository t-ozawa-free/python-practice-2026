# 問題2: 家計簿の食費集計

## 難易度
★☆☆☆☆ (基本)

## 課題
家計の状況を記録した「input/money_book.csv」から食費を集計し、詳細と合計を出力するプログラムを作成してください。

## 条件
* カテゴリーが「食費」のものだけを集計します
* 日付、品目、金額を一覧表示します
* 最後に合計金額を表示します
* 金額は3桁ごとに `,` をつけて表示します

## 入力ファイル
`input/money_book.csv`

## 出力形式例
```
食費の集計
==================
2024-01-01: スーパーマーケット - 3,500円
2024-01-03: コンビニ - 800円
2024-01-05: レストラン - 2,500円
...
==================
食費合計: 45,800円
```

## ヒント
* CSVを読み込んで、カテゴリーが「食費」の行をフィルタリングします
* リストに追加しながら合計を計算できます
