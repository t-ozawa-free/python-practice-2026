# 問題9: プロジェクトタスク進捗管理

## 難易度
★★★★☆ (実務レベル)

## 課題
プロジェクトのタスク情報が記録された「input/project_tasks.csv」から、各担当者の進捗状況と遅延タスクを分析し、レポートを出力してください。

## 条件
* ステータスは「未着手」「進行中」「完了」「遅延」の4種類です
* 期限が基準日（2024/01/31）を過ぎている「進行中」「未着手」タスクは「遅延」として扱います
* 担当者ごとに以下を集計します：
  - タスク総数
  - 完了タスク数と完了率
  - 遅延タスク数
  - 予定工数合計と消化工数合計
* 遅延タスクがある担当者には警告マークを表示します
* 完了率の高い順に並べて出力します

## 入力ファイル
`input/project_tasks.csv`

## 出力形式例
```
プロジェクト進捗レポート
基準日: 2024-01-31
==================
担当者: 山田太郎 ⚠️
総タスク数: 8件
完了: 5件 (62.5%)
進行中: 2件
遅延: 1件
予定工数: 40.0h / 消化工数: 28.0h (70.0%)
------------------
担当者: 佐藤花子
総タスク数: 6件
完了: 5件 (83.3%)
進行中: 1件
遅延: 0件
予定工数: 32.0h / 消化工数: 26.0h (81.3%)
------------------
...
==================
プロジェクト全体:
総タスク数: 30件
完了率: 70.0%
遅延タスク: 5件
全体進捗: 73.5%
```

## ヒント
* `datetime.strptime()` で日付を比較します
* 辞書を使って担当者ごとにデータを集計します
* 期限と基準日を比較して遅延を判定します
