# 問題1: 勤務時間計算と給与明細出力

## 難易度
★☆☆☆☆ (基本)

## 課題
1か月間の勤務情報が保存されている「input/timecard.csv」から勤務時間を計算し、給与明細を「output/salary.txt」に出力するプログラムを作成してください。

## 条件
* 時給は1050円で計算します
* 開始から終了までを勤務時間とします（休憩時間は無視）
* 支給金額は `総勤務時間 * 時給` で計算します
* 支給金額の小数点以下は切り捨てます
* 支給金額は3桁ごとに `,` をつけて出力します（例: `136,500円`）
* 日付は `%m-%d` 形式で出力します（例: `01-01`）
* 勤務記録は「日付, 開始時刻, 終了時刻, 勤務時間」の形式で出力します
* 各カンマの後ろに半角スペース1つを入れます

## 入力ファイル
`input/timecard.csv`

## 出力ファイル
`output/salary.txt`

## 出力形式例
```
給与明細
==================
01-01, 10:00, 15:00, 5.0時間
01-03, 10:00, 15:00, 5.0時間
01-05, 16:00, 21:00, 5.0時間
...
==================
総勤務時間: 100.0時間
支給金額: 105,000円
```

## ヒント
* `datetime.strptime()` を使って時刻を計算できます
* `int()` で小数点以下を切り捨てられます
* `format()` や f-string で3桁区切りができます
