# 問題3: 商品在庫管理

## 難易度
★☆☆☆☆ (基本)

## 課題
商品の在庫情報が記録された「inventory.csv」から、在庫が10個以下の商品を抽出し、発注が必要な商品リストを「reorder_list.txt」に出力してください。

## 条件
* 在庫数が10個以下の商品を抽出します
* 商品コード、商品名、現在庫数、発注推奨数を出力します
* 発注推奨数は「50 - 現在庫数」で計算します
* 在庫数が少ない順に並べて出力します

## 入力ファイル
`input/inventory.csv`

## 出力ファイル
`output/reorder_list.txt`

## 出力形式例
```
発注が必要な商品リスト
==================
商品コード: P001
商品名: ボールペン（黒）
現在庫数: 3個
発注推奨数: 47個
------------------
商品コード: P005
商品名: ノート（A4）
現在庫数: 8個
発注推奨数: 42個
------------------
合計: 2商品
```

## ヒント
* リストに在庫10個以下の商品を追加します
* `sorted()` 関数で在庫数順にソートできます
