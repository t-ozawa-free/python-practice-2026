# 問題4: 売上データの月次集計

## 難易度
★★☆☆☆ (基本)

## 課題
1ヶ月間の売上データが記録された「input/sales.csv」から、商品カテゴリーごとの売上を集計し、レポートを出力してください。

## 条件
* カテゴリーごとに売上金額を合計します
* 売上金額の高い順に並べて表示します
* 各カテゴリーの売上構成比（%）も計算します
* 構成比は小数点第1位まで表示します
* 金額は3桁ごとに `,` をつけて表示します

## 入力ファイル
`input/sales.csv`

## 出力形式例
```
月次売上レポート
==================
1位: 飲料 - 450,000円 (35.2%)
2位: 食品 - 380,000円 (29.7%)
3位: 日用品 - 280,000円 (21.9%)
4位: 雑貨 - 170,000円 (13.3%)
==================
総売上: 1,280,000円
```

## ヒント
* 辞書を使ってカテゴリーごとに集計できます
* `sorted()` で辞書を値でソートできます
* 構成比は `(カテゴリー売上 / 総売上) * 100` で計算します
